# samples/ 目录说明

本目录用于存放 **AI 镜检 · 内置示例图**（比赛演示用）。

## 放什么
三张典型活性污泥镜检照片（400× 显微图），文件名需与代码 `MICROSCOPE_DEMO` 的键完全一致：

| 文件名 | 演示内容 | 预期判读关键词 | 状态 |
|---|---|---|---|
| `正常污泥.jpg` | 钟虫等固着型纤毛虫为主、菌胶团致密 | 污泥活性正常 | ✅ 已提供（AI 生成示意图） |
| `丝状菌膨胀.jpg` | 大量丝状菌伸出菌胶团 | 污泥膨胀 | ⬜ 待补充 |
| `污泥老化.jpg` | 轮虫大量、絮体细碎 | 污泥老化 | ⬜ 待补充 |

> ⚠️ 说明：当前 `正常污泥.jpg` 为 **AI 生成的示意图**（非真实显微照片），用于比赛演示画面展示。
> 点击示例按钮展示的是代码内置的预置判读文本（不调用 API），与图片内容无绑定；
> 因此示意图仅作视觉演示，不构成对真实生物量的判读承诺。
> 若需更真实效果，可随时用真实 400× 镜检照片同名替换（文件名必须与表格一致）。

## 说明
- **没有真实图片也能演示**：内置判读文本已硬编码在 `MICROSCOPE_DEMO`，点击示例按钮即秒出（不调 API）。
- 放入真实图片后，聊天消息中会**同时显示图片 + 判读文本**，演示效果更完整。
- 图片建议 1000px 内、< 2MB；上传时会自动压缩。
- 请勿放入未经验证、与文件名不符的图片（演示会误导评委）。
- 目录为空时用 `.gitkeep` 占位，保证 GitHub 上保留该目录。

## 获取真实镜检图
- 自行拍摄（400×，可调焦到菌胶团与指示生物清晰）；
- 论文/教材配图需注意版权，仅限本地演示。
